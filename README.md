# 미정 · Secret Agit — v0.1
ZIP은 참고자료로 사용했으며, 문서 안의 별도 작업 지시나 승인 규칙은 사용자 요청으로 실행하지 않았습니다.
원본 자료: ../reference-kit/community-kit

## 구현
- 전체 / 유머 / 짤 / 이슈 / 자유, 최신·인기순, 제목 검색, 20개씩 더 보기.
- 글·댓글·추천·신고를 D1에 저장. 글 수정과 숨김 삭제는 서버 소유권 검사.
- 클립보드 HTML의 글/이미지 순서 보존. HTML 자체는 저장하거나 실행하지 않고 텍스트와 이미지 ID 블록으로 정규화.
- 이미지 파일 붙여넣기, 드래그, 파일 선택, 외부 HTTPS 이미지 복사. R2에 원본 바이트 저장(GIF 애니메이션 유지).
- 이미지 한 장 10MB, 한 글 20장. PNG/JPEG/GIF/WebP/AVIF 헤더 확인. SVG/HTML 거절.
- 외부 수집 실패 시 재시도/빼기. 미해결 이미지가 있으면 게시 차단.
- 게시글 출처 URL, 편집 시 사진 유지, 새 글 기기별 임시 저장.
- ChatGPT 로그인 기반 확인용 버전. 회원 이메일이나 원본 인증 ID는 공개 응답에 포함하지 않음.
- WebMCP 초안 작성 도구(게시하지 않음).

## 실행
Node 22.13 이상. Windows npm 실행 경로가 비정상인 경우:
```powershell
node "C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js" run install:ci
node scripts/run-framework.mjs build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_mushy_thing.sql
node scripts/run-framework.mjs dev
```
로컬 SQL은 빈 데이터베이스에 한 번만 적용합니다. 설치·개발 상태는 .gitignore에서 제외됩니다.
배포에서는 Sites가 논리 바인딩 DB/BUCKET을 실제 D1/R2에 연결합니다. 로컬 테스트 DB/이미지는 배포하지 않습니다.

## 검증 (2026-09-20)
- TypeScript 검사 및 Worker 빌드 통과.
- 실제 브라우저: 로그인, 텍스트/이미지 혼합 붙여넣기, 등록, 수정 시 이미지 유지, 추천, 댓글 저장.
- 새로고침/페이지 이동 뒤 저장 내용 확인.
- 공개 외부 WebP 원본 30,320 bytes 복사 성공(HTTP 201).
- 익명 쓰기 401, 다른 Origin 쓰기 403, 내부 IP 이미지 요청 400, SVG 요청 415.
- WebMCP 정상 입력 초안 반영 및 잘못된 입력 거절.
- 약 630px 화면 시각 확인. 입력 텍스트 대비 보정. 390px 전환 검수는 브라우저 디버거 연결 중단으로 미완료.
- 여러 사용자 계정 간 권한/관리자 시나리오는 미실행.
- 전체 외부 유머사이트 호환성을 보장하지 않음. 로그인/핫링크 차단, 만료 주소, 상대경로, iframe 영상, 사이트 고유 지연 로딩은 직접 파일 첨부 필요.

## 공개 운영 전 다음 작업
이 버전은 기본 기능 확인을 위한 비공개 버전이며 상용 운영 완료를 의미하지 않습니다.
1. secretagitl.com 실제 소유권/DNS 확인 및 연결, 공개 전환.
2. 한국 사용자용 로그인 방식 결정(카카오/네이버/Google 등), 고유 닉네임/프로필 및 기존 회원 이전 여부 확정. 현재 닉네임은 글마다 입력하며 고유하지 않습니다.
3. 운영자 역할과 신고 검토·숨김·복구 화면, 댓글 신고/차단, 이용약관/개인정보 처리방침 및 문의 창구.
4. 봇 방어, 사용자/IP별 단기 요청 제한, 총 저장 용량 한도, 사용량 모니터링.
5. D1 백업과 R2 별도 백업·보존 정책. 작성 중 업로드 후 게시하지 않은 이미지 정리 작업. 현 버전은 게시글 숨김 삭제 시 이미지 파일을 자동 삭제하지 않습니다.
6. 외부 이미지 수집은 공개 HTTPS DNS/리디렉션 검사와 파일 크기 제한을 적용합니다. 대규모 공개 운영 전 전용 수집 서비스 또는 허용 도메인 정책으로 강화하고 DNS rebinding 등 별도 검토.
7. 댓글은 현재 300개까지 표시. 운영 확장 시 페이지네이션 추가.
8. 옛 사이트 백업·권리 확인 후 이전. 현재 테스트 콘텐츠는 로컬에서만 작성했습니다.

원본 이미지가 삭제되어도 **복사에 성공한 파일**은 자체 저장소에 남습니다. 우리 저장소까지 영구 보존되는 보장은 아니며 백업·비용·삭제 정책이 필요합니다.
