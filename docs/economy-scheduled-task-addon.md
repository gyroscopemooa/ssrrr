# 포트폴리오 전용 알림 — 사이트 전송 추가 지시문

기존 예약 작업 지시문 맨 아래에 다음 문단을 추가한다.

```text
실제 알림을 출력하는 실행에서는 최종 제목과 전체 본문을 완성한 뒤 SSRRR 사이트의 `submit_economy_report` 도구를 정확히 한 번 호출하라. `title`에는 최종 알림 제목을, `body`에는 화면에 출력할 내용을 요약하거나 자르지 말고 첫 줄 `SSRRR_ECONOMY`부터 마지막 출처까지 전체 그대로 넣어라. `idempotencyKey`는 생략해도 된다. 이 전송은 관리자 검수함에만 저장되며 자동 공개되지 않는다. 알림 조건을 충족하지 않아 원래 아무 알림도 출력하지 않는 실행에서는 이 도구를 호출하지 마라. 도구 전송에 실패하면 성공한 것처럼 말하지 말고 실패 사실을 알리되, 기존 화면 알림 자체는 그대로 출력하라.
```

## 동작

- 기존 ChatGPT 예약 작업이 조사와 글 생성을 계속 담당한다.
- 사이트 도구는 완성된 원문을 새로 생성하지 않고 그대로 전달한다.
- 사이트에는 `검수 필요` 상태로 저장되며 관리자가 확인한 뒤 게시한다.
- 첫 줄이 정확히 `SSRRR_ECONOMY`가 아니면 거부한다.
- 동일한 본문이 재전송되면 중복 저장하지 않는다.
- 알림이 없는 실행은 사이트 호출도 하지 않는다.

## 비용 구조

- OpenAI 개발자 API 키를 사용하지 않는다.
- 도구 호출 자체에 별도의 OpenAI API 종량제 청구를 붙이지 않는다.
- 기존 예약 작업이 사용하는 ChatGPT 플랜 사용량은 그대로 적용된다.
