# 운영 기본값

## 사이트 글
- 약 20개 소스
- 기본 소스당 1개
- 좋은 소스 2~3개 가능
- 19:00 시작
- 3분 간격
- 약 1시간 내 게시

## 쇼츠
- target 40초
- min 25초
- preferred 30~55초
- operational max 60초
- max posts 2
- comments ON / 최대 3
- BGM ON / 10~15%
- video with audio → BGM OFF
- watermark ON
- 업로드 default private 또는 scheduled

## 매일 권장 흐름
1. 자동수집
2. 사이트 글 게시
3. 쇼츠 후보 계산
4. 운영자 3~5개 선택
5. 일괄 생성
6. QC
7. 승인
8. YouTube 예약
9. 성과 동기화

쇼츠 자동생성까지 완전 무인화하는 것은 V1 기본값이 아니다.
